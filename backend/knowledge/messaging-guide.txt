MESSAGING ACCESS RULES

Messages are protected and require an authenticated account.

The current messaging rule is:

1. An application must exist between the jobseeker and employer.
2. The employer may start the conversation.
3. A jobseeker cannot send the first message in a new conversation.
4. After the employer creates the first message, both sides can continue the existing conversation.
5. A user cannot message the same account as both sender and receiver.

If a jobseeker tries to begin a new conversation before the employer, the system returns the instruction to wait for the employer to message first.

MESSAGE FEATURES

The messaging backend supports text, interview, follow-up, instruction, notification, and file message types. Conversations can be listed, opened, marked as read, and counted for unread messages. The message upload route has a 10 MB file-size limit.

INTERVIEW MESSAGES

Scheduling an interview can create a structured interview message containing date, time, location or interview type, and notes or instructions. Interview scheduling can also create a notification.

CONVERSATION PREFERENCES

The system stores user-specific conversation preferences such as archived, hidden company, and deleted states. These preferences affect how a conversation is shown to that user without changing the other user's copy in the same way.

PRIVACY

Agap-AI must not claim that it read a user's messages. The current chatbot route has no approved tool for retrieving private message content. It may explain how Messages works but must not reveal or invent conversation data.


HOW TO USE AN EXISTING CONVERSATION

1. Sign in and open Messages.
2. Select the available company or candidate conversation.
3. Read previous messages within your authorized account.
4. Type and send a professional reply or attach a supported file when enabled.
5. Review new interview or follow-up details in the conversation and Notifications.

ATTACHMENT PREVIEWS

The frontend may allow users to open image or document attachments, preview available files, and download them. Images and documents can have different preview/download controls. Actual behavior depends on the current user interface and file type. Uploaded message files are subject to the stated 10 MB backend limit, and additional file-type restrictions may apply.

INTERVIEW AND STATUS COMMUNICATION

Interview scheduling can produce a structured message with date/time, format, notes, and employer-provided instructions when applicable. Do not claim that AGAPAY automatically generates an external meeting link. Sending a normal message does not itself update an application status or official interview schedule.

CONVERSATION VISIBILITY AND PRIVACY

Archive, hidden-company, and delete preferences may affect one user's view independently of the other participant. Users should not expect Agap-AI to inspect, recover, or disclose private conversations, even if asked to impersonate the other party.

IF YOU CANNOT SEND A MESSAGE

Confirm that there is an eligible application and that the employer has initiated the conversation if you are the jobseeker. Check your login, internet connection, and any visible error. Do not send repeated copies until you know the first request failed.

WHEN CAN EMPLOYERS INITIATE MESSAGES?
An employer cannot message an arbitrary jobseeker without an eligible application linking those accounts. Once that application exists, the employer can send the first message. The jobseeker must wait for the employer's first message before replying. An ordinary message does not itself change the official hiring stage or job application status.
